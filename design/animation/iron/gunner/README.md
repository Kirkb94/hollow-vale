# Dwarf Gunner - layered Arcane Vanguard art

Generated using built-in image generator; exact prompts saved in prompts.json. Original transparent PNG sheets unchanged. Source rectangles and optional island isolation assemble twelve independently movable body pieces across six facings. Equipment follows articulated hands.

Validated seven poses in all six directions (42). Actual gameplay, visual effects, pause/resume, fog and board zoom pass tools/iron-vanguard.test.cjs.

Separate firearm with aimed shooting arms; muzzle flash, projectile and impact. Source supplied one forearm per facing, so second forearm reuses mirrored cutout. Short dwarf proportions use independent body scale.

Visual effect sprites, not new audio recordings. Balance unchanged.
